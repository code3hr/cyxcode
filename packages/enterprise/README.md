# @cyxcode/enterprise

Enterprise CyxCode web app and deployment surface.

## Commands

Run these from this directory:

```sh
bun install
bun run dev
bun run build
bun run build:cloudflare
bun run typecheck
```

`build:cloudflare` targets the Cloudflare deployment path used by the hosted console.

## Notes

- `src` contains the app code.
- `sst-env.d.ts` is generated by SST.
- `shell-prod` opens an SST shell against the production Teams target.
