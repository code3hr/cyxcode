# @cyxcode/app

Shared CyxCode UI package built with Solid and Vite.

## Commands

Run these from this directory:

```sh
bun install
bun run dev
bun run build
bun run typecheck
bun run test:unit
```

## Notes

- `src` contains the reusable app UI.
- `test:e2e:local` runs the local end-to-end harness against a seeded backend.
- `src/index.css` and `vite.js` are exported for consumers in the workspace.
