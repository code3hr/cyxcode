[**CyxCode**](/) is an open source AI coding agent. It's available as a terminal-based interface, desktop app, or IDE extension.

![CyxCode TUI](../../../assets/lander/screenshot.png)

Let's get started.

---

#### Prerequisites

To use CyxCode in your terminal, you'll need:

1. A modern terminal emulator like:
   - [WezTerm](https://wezterm.org), cross-platform
   - [Alacritty](https://alacritty.org), cross-platform
   - [Ghostty](https://ghostty.org), Linux and macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux and macOS

2. API keys for the LLM providers you want to use.

---

## Install

The easiest way to install CyxCode is through the install script.

```bash
curl -fsSL https://cyxcode.ai/install | bash
```

You can also install it with the following maintained options:

- **Using Mise**

  ```bash
  mise use -g github:code3hr/cyxcode
  ```

- **Installing on Arch Linux**

  ```bash
  paru -S cyxcode-bin
  ```

- **Using Docker**

  ```bash
  docker run -it --rm ghcr.io/code3hr/cyxcode
  ```

- **From source**

  ```bash
  git clone https://github.com/code3hr/cyxcode
  cd cyxcode
  bun install
  bun run dev
  ```

#### Windows

:::tip[Recommended: Use WSL]
For the best experience on Windows, we recommend using [Windows Subsystem for Linux (WSL)](/docs/windows-wsl). It provides better performance and full compatibility with CyxCode's features.
:::

## Configure

With CyxCode you can use any LLM provider by configuring their API keys.

If you are new to using LLM providers, start with the provider setup in the main documentation.

1. Run the `/connect` command in the TUI.

   ```txt
   /connect
   ```

2. Choose the provider you want to use.
3. Sign in or paste the provider API key when prompted.
